A

Split into training and test set.

train <- sample(1:nrow(Carseats), nrow(Carseats)/2)

B

Fit a regression tree to the training set. Plot the tree and interpret the results.

tree_fit <- tree(Sales ~ ., data = Carseats_train)

# Plot tree
plot(tree_fit)
text(tree_fit, pretty = 0)

tree_pred <- predict(tree_fit, newdata = Carseats_test)

# Test MSE
mean((tree_pred - Carseats_test$Sales)^2)
## [1] 4.922039

C

Use cross-validation to determine the optimal level of tree complexity. Does pruning the tree improve the test MSE?

set.seed(1)

cv_tree <- cv.tree(tree_fit)

# Plot CV results
plot(cv_tree$size, cv_tree$dev, type = "b",
     xlab = "Tree Size", ylab = "Deviance")

# Find best size using CV
best_size <- cv_tree$size[which.min(cv_tree$dev)]

# Prune tree
pruned_tree <- prune.tree(tree_fit, best = best_size)

# Plot pruned tree
plot(pruned_tree)
text(pruned_tree, pretty = 0)

# Test MSE
pruned_pred <- predict(pruned_tree, newdata = Carseats_test)
mean((pruned_pred - Carseats_test$Sales)^2)
## [1] 4.922039
